# Request for Proposal: Sparrow Deck for Learning MTG Color Combos

We at MTG Deck Builder are seeking a new application to help new players adapt to the language used in the MTG community. That language can be very specific and unique, and nowhere does this strike quickly and harshly as in the words created to describe color combinations.

Meanwhile, our CEO, Jessitron, has experienced very quick learning of names using Llewellyn Falco's "Sparrow Deck" technique. We seek to create a static web application that functions as a kind of "Sparrow Deck" for MTG color combinations.

We seek a firm to research these concepts ("Sparrow Deck" and "MTG Color Combination Names"), help design and then fully build a static web application to help new players name color combinations in a blink.

This RfP is deliberately sparse, because we will have more ideas together than separately.
