# Session: 2026-03-26 — Combo Pages & Card Expansion

## What we built

### Static combo pages (`combo/`)
- 20 detail pages + index page, generated by `npm run build:combos`
- SEO-friendly: unique titles, meta descriptions, Open Graph images, canonical URLs
- Each page: breadcrumb nav, pentagon SVG with turquoise highlighted lines, guild crest (guilds only), description, optional flavor text, "Learn X names" CTA button, card gallery, Scryfall link
- Index page: card grid layout (5/3/2 columns responsive), "Learn these names" buttons per group
- Linked from end page ("More X cards" → combo page instead of Scryfall)
- Breadcrumb fixed-position next to home spiral

### Card data expansion
- All 20 combos now have 20+ cards (400+ total)
- Verified Scryfall image URLs via batch lookup scripts
- No split cards (render sideways), no double-faced cards
- Color-identity cards OK (signets, lands) — they reinforce name recognition
- Personal favorites added: Umbris Furby edition (Dimir), Ygra + Chatterfang (Golgari)

### Data model additions
- `CardReference.flavor?: string` — snarky alt text per card
- `GuildDescription.flavor?: string` — editorial commentary per combo

### New scripts
- `npm run build:combos` — generate all combo HTML pages
- `npm run summarize:combos` — print card data summary
- `scripts/lookup-card.sh` — single card Scryfall lookup
- `scripts/batch-lookup-cards.sh` — batch card lookup, outputs TypeScript entries
- `scripts/README.md` — documents all scripts

### Design decisions
- Static HTML not SPA (SEO)
- No visible color names ("White / Blue") — teach combo names, not colors
- Color names in aria-label, meta tags, alt text only
- Mana pip images everywhere, never emoji in rendered HTML
- No hamburger menu on combo pages (pure static)
- Turquoise (#6C9FB0) for highlighted pentagon lines
- Level order: allied, enemy, wedges, shards
