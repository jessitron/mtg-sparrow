## Observations

- **Static HTML welcome is immediately visible** — there is no JS-generated delay before the welcome screen appears. This is an improvement over v0.5.0 where JS had to run `showWelcomeScreen()` first.
- **`page.content()` is the right tool** for verifying static HTML content. It returns the current live DOM, which for a static welcome screen should contain the content directly (not injected).
- **Playwright `waitForFunction` pattern** (detecting class removal) continues to be the most robust way to verify auto-reveal. Recommend keeping this pattern.
