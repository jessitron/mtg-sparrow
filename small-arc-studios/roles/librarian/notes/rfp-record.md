# RFP Record: Sparrow Deck for MTG Color Combinations

## Date Received
2026-02-15

## Client
MTG Deck Builder (CEO: Jessitron)

## Original Request Summary
The client seeks a static web application that applies Llewellyn Falco's "Sparrow Deck" learning technique to help new Magic: The Gathering players rapidly learn the community names for color combinations.

## Key Points from RFP
- **Problem**: MTG community language is specific and unique; color combination names are a steep learning curve for new players.
- **Inspiration**: The CEO has personally experienced rapid name learning via the Sparrow Deck technique.
- **Deliverable**: A static web application functioning as a Sparrow Deck for MTG color combinations.
- **Scope**: Research (both Sparrow Deck technique and MTG color combination names), design, and full build.
- **Philosophy**: "We will have more ideas together than separately" — the RFP is deliberately sparse, inviting collaborative design.

## Research Areas Identified
1. Sparrow Deck technique — structure, mechanics, what makes it effective
2. MTG Color Combination Names — guilds, shards, wedges, nephilim, WUBRG
