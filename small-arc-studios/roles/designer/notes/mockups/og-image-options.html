Designer notes:
  • Logo fidelity: This uses the exact same technique as src/ui/logo.ts — a conic-gradient circle (W gold -> U teal -> B purple -> R orange -> G green) masked by the spiral SVG path from images/spiral.svg. The five mana pip symbols are positioned in a pentagon using the same cosine/sine offsets as the source.
  • Background: Restored Option 3's exact background values — off-center radial gradient (#5a3f1f -> #3a2810 -> #1c1a10), guild watermarks at 12% opacity with saturate(0.5) brightness(1.2), and the atmospheric off-center vignette (ellipse at 30% 50%).
  • Mana pips: Plain black silhouettes with no colored circle backgrounds, matching the About page logo exactly.
  • Text hierarchy: "MTG Colors" at 84px GoudyMediaeval (the site's actual display font, loaded via @font-face), then a 26px Jost tagline in khaki (#c8b88a). Both remain legible at thumbnail size.
  • Accent bar: Five 80px segments in WUBRG order — a subtle color key at the bottom of the composition.
  • For final PNG generation: Use Puppeteer or html-to-image to render this at 1200x630. GoudyMediaeval is now loaded via @font-face from the project font directory. The CSS mask technique works in all modern browsers.
